# YouTube Thumbnail Downloader

A clean, responsive single-file web application for previewing and downloading YouTube video and Shorts thumbnails across all standard available resolutions. Built with vanilla HTML5, CSS3, and JavaScript featuring a dark glassmorphic interface and smooth micro-interactions.

## Features

- **All Standard Resolutions:** Extracts thumbnails from `1280 × 720` (HD 720p) down to `120 × 90` (Default), supporting standard watch links, `youtu.be` short links, embeds, and YouTube Shorts URLs.
- **Smooth Animated Interface:** Dark glassmorphic UI with floating ambient glows, staggered card entrance animations, hover zoom previews, and shimmer loading skeletons.
- **Fast Workflow:** Includes one-tap clipboard **Paste**, **Clear**, direct **Download**, and **Copy Image URL** buttons.
- **Resilient Fallbacks:** Gracefully handles metadata request timeouts and cross-origin download restrictions without breaking the UI.
- **Mobile & Desktop Friendly:** Responsive layout designed to work smoothly across phones, tablets, and laptops.
